Market sizing pass for the BIRDING / WILDLIFE TOURS niche (multi-day, fixed-date group trips).

**Why:** Swellyo is exploring which vertical of group-trip organizers to target beyond surf. Birding was researched 2026-09-10.

**How to apply:** Reuse these anchors instead of re-searching. Re-verify prices before quoting to anyone.

## Hard anchors found (with dates)
- **Global Birdfair 2026 exhibitor list = 354 exhibitors** (https://www.globalbirdfair.org/list-of-exhibitors, as of 2026-09-10). ~20-22% of them are qualifying multi-day trip organizers (~71 by my classification). Rest = optics, art, NGOs, tourist boards, lodges.
- **Rockjumper Birding Tours = "300 scheduled tours annually"**, split Africa/Madagascar 80, Asia 88, S America 64, Australasia 29, N America 28, Europe 20, C America 20, Caribbean 12, Antarctic 5. Group size 1 leader : up to 8 guests. $842,848 donated to conservation since 2018. (https://www.rockjumperbirding.com/, 2026-09-10)
- **Field Guides Inc. = "150 annual departures", "136 itineraries"**, Austin TX. (https://fieldguides.com/, 2026-09-10)
- **Fatbirder geo_link sitemap = 1,081 URLs** (country/region pages). NOT an operator count — could not extract per-country operator listings; WebFetch only returns nav menus for fatbirder.com. There is NO published "birding tour operators" total on Fatbirder that I could reach.

## Estimate reached
1,500-4,000 qualifying global operators; central ~2,000-2,500. If you require *published fixed departures* (not custom/private), drop to ~600-1,200.
