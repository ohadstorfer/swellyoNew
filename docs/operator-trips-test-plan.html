Nine feature commits and fourteen migrations, all applied to production. This is the walk-through: what to poke, how to set the state up, and what counts as passing. Grouped by risk — money first, then the things that fail silently.

Before you touch anything

Group trips are live on prod with real users. Every test below must run on a trip whose participants are all dev accounts. Cancelling a trip now refunds everyone automatically — on the wrong trip that is real money and real pushes.

Stripe is in test mode. Refunds need a funded test balance: scripts/fund-test-balance.sh.

Several checks want a push to arrive. Push is dead in Expo Go — use a dev build, or verify by reading notification_queue instead of waiting for the phone.

Handy while testing. Force any scheduled job to run now rather than waiting for its slot, and read what the gateway answered:

-- copy the command out and execute it directly, then:
